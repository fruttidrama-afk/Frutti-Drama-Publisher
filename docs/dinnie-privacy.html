Dinnie Publisher Privacy Policy

Last updated: September 25, 2026

Dinnie Publisher is a private content-publishing application used to manage and publish authorized content to the Dinnie The Dinosaur Facebook Page.

Information we access

When an authorized operator connects Facebook, the application may access basic Facebook account information required by Meta, Page identity information, Page permissions, and access tokens needed to publish content to the selected Facebook Page.

How we use information

We use this information only to authenticate the authorized operator, identify the selected Facebook Page, publish approved video content, and verify publication status.

Storage and security

Authentication credentials and tokens are stored in private application infrastructure and are not displayed publicly. We do not sell personal information and do not use Facebook data for advertising.

Sharing

We do not sell or rent user information. Information is shared only with service providers necessary to operate the application and with Meta/Facebook as required to perform the requested publishing actions.

Data retention

We retain authorization data only for as long as it is needed to operate the connected publishing workflow. Authorization data may be replaced or removed when the Facebook connection is refreshed or disconnected.

Data deletion

An authorized user can request deletion of application-held Facebook authorization data by following the instructions on our Data Deletion Instructions page.

Contact

For privacy or data-deletion questions regarding Dinnie Publisher, contact the application owner through the account associated with the Dinnie The Dinosaur Page.
